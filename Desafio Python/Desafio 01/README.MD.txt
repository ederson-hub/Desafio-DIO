# 💻 ETL

Criando um pipeline ETL

## Tecnologia
Construindo um pipeline ETL em python.
Começando com a simples extração de IDs de usuários de uma planilha, seguindo para uma transformação de salário por cargo, e culminando no carregamento desses dados transformados em um JSON.
